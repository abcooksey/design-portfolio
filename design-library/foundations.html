Foundations

Elevation & Borders

Shadows, border radii, and visual depth create hierarchy and help users understand interactive surfaces. These foundations establish the visual language for cards, buttons, and other elevated elements.

Shadows

A progression of shadow depths for different elevation levels. Shadows use subtle opacity to feel natural and not overpowering.

--shadow-sm
Subtle lift, hover states
--shadow-md
Medium elevation
--shadow-lg
Popovers, dropdowns
--shadow-xl
Modals, prominent cards
--shadow-card
Default card shadow (tinted)
--shadow-card-hover
Card hover state
Token Value
--shadow-sm 0 1px 2px 0 rgba(0, 0, 0, 0.05)
--shadow-md 0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -2px rgba(0, 0, 0, 0.1)
--shadow-lg 0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -4px rgba(0, 0, 0, 0.1)
--shadow-xl 0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 8px 10px -6px rgba(0, 0, 0, 0.1)
--shadow-card 0 4px 20px rgba(124, 58, 237, 0.08)
--shadow-card-hover 0 12px 40px rgba(124, 58, 237, 0.15)
💡
Card shadows use the primary purple color (7C3AED) at low opacity to create a subtle branded tint. This adds warmth compared to neutral gray shadows.

Z-Index Scale

A structured z-index scale prevents stacking conflicts and ensures proper layering of overlapping elements.

Token Value Usage
--z-dropdown 100 Dropdown menus, select options
--z-sticky 200 Sticky headers, pinned elements
--z-fixed 300 Fixed navigation bar
--z-modal-backdrop 400 Dark overlay behind modals
--z-modal 500 Modal dialogs, lightbox
--z-tooltip 600 Tooltips (above all other content)
💡
The lightbox component uses z-index: 9999 to ensure it appears above all other content including the navigation.

Transitions

Consistent transition timing creates smooth, predictable interactions.

Token Value Usage
--transition-fast 150ms ease Color changes, small interactions
--transition-base 250ms ease Default for most components
--transition-slow 350ms ease Larger state changes, reveals
--transition-bounce 500ms cubic-bezier(0.34, 1.56, 0.64, 1) Playful bouncy animations
