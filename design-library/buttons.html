Components

Buttons

Buttons communicate actions users can take. They have multiple variants for different levels of visual prominence and use cases.

Anatomy

A button consists of a text label and container with interactive states.

Container Button Label Text Label
1 Container: Background fill or border that defines the button bounds
2 Text Label: Describes the action; uses heading font at semibold weight
3 Icon (optional): Can appear before or after text for additional context

Variants

Three button variants provide different levels of visual emphasis.

Primary Button

High emphasis. Use for the most important action on a page, like "View Work" or "Get in Touch".

Primary Button
Background--color-primary (#7C3AED)
Text Color--color-white (#FFFFFF)
Shadow0 4px 14px rgba(124, 58, 237, 0.3)
Border Radius--radius-lg (12px)

Secondary Button

Medium emphasis. Use alongside primary buttons for secondary actions.

Secondary Button
Background--color-white (#FFFFFF)
Text Color--color-primary (#7C3AED)
Border2px solid --color-primary
Border Radius--radius-lg (12px)

Ghost Button

Low emphasis. Use for tertiary actions or in dense UIs where other variants would be too heavy.

Ghost Button
Backgroundtransparent
Text Color--color-text-primary (#334155)
Bordernone
Border Radius--radius-lg (12px)

Guidelines

✓ Do
  • Use action verbs: "View Work", "Get in Touch", "Read Case Study"
  • Limit to one primary button per section
  • Place primary actions on the left in button groups
  • Ensure sufficient contrast on all backgrounds
✗ Don't
  • Use vague labels like "Click Here" or "Submit"
  • Stack more than 2-3 buttons together
  • Use primary buttons for every action
  • Nest buttons inside other buttons
