Colors

The color palette establishes visual hierarchy and brand identity. Colors are defined as CSS custom properties for consistent use across the site.

Usage Guidelines

✓ Do
  • Use primary color for main CTAs and interactive elements
  • Apply text-secondary for supporting content
  • Use subtle backgrounds to create visual hierarchy
  • Maintain WCAG AA contrast ratios (4.5:1 for text)
✗ Don't
  • Place light text on light backgrounds
  • Overuse the primary color - it should guide attention
  • Mix competing gradients in close proximity
  • Use color as the only indicator of state
