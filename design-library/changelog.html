Version History

v1.0.0 March 2026

Initial Release

First version of the design library with comprehensive documentation of the portfolio's visual language.

Added:
  • Token extraction script for automated data generation
  • Colors documentation with all palette variations
  • Typography scale and font family documentation
  • Spacing system based on 8px grid
  • Elevation, shadows, and border radius tokens
  • Button component with variants and states
  • Card component with project card variation
  • Navigation patterns (header, footer, mobile)
  • Form element recommendations
  • Content patterns (heroes, stats, testimonials)
  • Interaction and animation documentation
  • GitHub Action for automatic updates

How Updates Work

Automatic Extraction

A Node.js script parses the CSS files to extract design tokens and component classes.

node scripts/extract-tokens.js

GitHub Action

On every push to main, the extraction script runs and commits updated data files if changes are detected.

Workflow: .github/workflows/update-design-library.yml
💡
What's auto-generated vs. manual:
Auto-generated: Token values, component class lists, generation timestamps
Manual: Usage guidelines, anatomy descriptions, code examples, this changelog

Generated Data Files

File Contents
data/tokens.json All CSS custom properties organized by category
data/components.json Discovered component classes with source file references
data/animations.json Keyframe animations and transition patterns
data/meta.json Generation timestamp and statistics

Contributing to the Library

Adding New Documentation

  1. Update CSS files
    Add or modify styles in css/variables.css or css/components.css
  2. Run extraction script
    Execute node scripts/extract-tokens.js to regenerate data files
  3. Update HTML documentation
    Add examples and guidelines to the relevant page in design-library/
  4. Update this changelog
    Document the changes with a new version entry
  5. Commit and push
    The GitHub Action will update data files automatically on push
