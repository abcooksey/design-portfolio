Foundations

Spacing

A consistent 8px-based spacing scale creates visual rhythm and hierarchy. Spacing tokens are used for margins, padding, gaps, and layout dimensions.

Spacing Scale

The spacing system uses a base unit of 4px, with most common values being multiples of 8px for optimal alignment with the pixel grid.

--space-1 0.25rem / 4px
Tight spacing, icon gaps
--space-2 0.5rem / 8px
Small gaps, inline spacing
--space-3 0.75rem / 12px
Button padding (vertical)
--space-4 1rem / 16px
Card content padding, standard gap
--space-5 1.25rem / 20px
Project card content padding
--space-6 1.5rem / 24px
Default grid gap, container padding
--space-8 2rem / 32px
Section header margin, testimonial padding
--space-10 2.5rem / 40px
Large gaps
--space-12 3rem / 48px
Section padding (default), two-col gap
--space-16 4rem / 64px
Large section padding, hero padding
--space-20 5rem / 80px
Extra large spacing
--space-24 6rem / 96px
Major section breaks
--space-32 8rem / 128px
Hero/case study top padding

Container Widths

Maximum width constraints for content containers at different breakpoints.

Token Width Usage
--container-sm 640px Narrow content, forms
--container-md 768px Medium content blocks
--container-lg 1024px Standard content width
--container-xl 1200px Default container (main content)
--container-2xl 1400px Wide layouts, full-width sections
