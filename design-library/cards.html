Components

Cards

Cards group related content and actions. They serve as entry points to more detailed information and provide consistent containers for various content types.

Anatomy

Cards have a flexible structure that can include images, content areas, tags, and actions.

1. Image Area (optional)
2. Tags
3. Title

4. Description text that explains the card content.

1 Image Area: Visual preview, optional depending on card type
2 Tags: Category labels using the tag component
3 Title: Card heading in semibold, 18px
4 Description: Supporting text in secondary color
