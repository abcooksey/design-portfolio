Interactions & Motion

Animation and interaction patterns add polish and delight without overwhelming the content. All animations are performant and respect user preferences for reduced motion.

Transition Timing

Consistent timing creates predictable, polished interactions.

Token Duration Easing Use Case
--transition-fast 150ms ease Color changes, small states
--transition-base 250ms ease Most component transitions
--transition-slow 350ms ease Large reveals, page transitions
--transition-bounce 500ms cubic-bezier(0.34, 1.56, 0.64, 1) Playful, bouncy effects
💡
The bounce easing creates an overshoot effect — the element briefly moves past its destination before settling. Use sparingly for delightful moments.

Performance Considerations

✓ Best Practices
  • Use transform and opacity for animations (GPU accelerated)
  • Use will-change sparingly on frequently animated elements
  • Use Intersection Observer instead of scroll event listeners
  • Use requestAnimationFrame for JavaScript animations
  • Respect prefers-reduced-motion media query
✗ Avoid
  • Animating width, height, or top/left
  • Long animations (>500ms) for UI transitions
  • Animations that block user interaction
  • Excessive motion that could cause discomfort
