Foundations

Typography

Typography establishes hierarchy, readability, and brand personality. The type system uses two complementary font families with a clear scale for consistent visual rhythm.

Font Families

Two carefully selected typefaces work together: a geometric sans-serif for headings and a highly legible humanist sans-serif for body text.

Plus Jakarta Sans
--font-heading

A geometric sans-serif with friendly, modern character. Used for headings, buttons, and navigation elements.

Medium 500 Semibold 600 Bold 700
Inter
--font-body

A highly legible humanist sans-serif optimized for screen reading. Used for body text, descriptions, and UI elements.

Font Weights

Four weight levels create clear hierarchy without overwhelming variation.

Token Value Usage Sample
--font-normal 400 Body text, descriptions The quick brown fox
--font-medium 500 Navigation, labels, emphasis The quick brown fox
--font-semibold 600 Buttons, card titles, subheadings The quick brown fox
--font-bold 700 Headings, stats, strong emphasis The quick brown fox

Line Heights

Line heights are tuned for optimal readability at each scale level.

Token Value Usage
--leading-tight 1.1 Large display headings, hero text
--leading-snug 1.25 Section headings, card titles
--leading-normal 1.5 Body text, paragraphs
--leading-relaxed 1.625 Long-form content, descriptions

Letter Spacing

Subtle tracking adjustments enhance readability and visual hierarchy.

Token Value Usage
--tracking-tight -0.025em Large headings where negative tracking improves density
--tracking-normal 0 Default for most text
--tracking-wide 0.025em Uppercase text, small labels, section markers
